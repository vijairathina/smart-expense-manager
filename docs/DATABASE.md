# Database Documentation - Expense Manager

## SQLite Database
- **Path**: `data/expense_manager.db`
- **Driver**: SQLite 3 with SQLAlchemy 2.0 ORM
- **Journal Mode**: WAL (Write-Ahead Logging)
- **Foreign Keys**: Enabled (`PRAGMA foreign_keys=ON`)

## Tables
1. **`users`**: Administrative accounts and credentials.
2. **`categories`**: Main spending categories with color badges and icons.
3. **`subcategories`**: Granular classifications linked to categories.
4. **`payment_modes`**: Cash, UPI, Credit Card, etc.
5. **`expenses`**: Primary transaction records with date, amount, description, source, and audit timestamp.
6. **`budgets`**: Monthly spending limits per category.
7. **`expense_queue`**: Incoming raw messages awaiting batch AI extraction.
8. **`settings`**: Key-value JSON storage for app configurations and AI keys.
9. **`audit_logs`**: System activity and data modification events.

## Backup Procedure
Automated daily snapshots run at 03:00 AM. Snapshots are stored in `backups/expense_manager_YYYYMMDD_HHMMSS.db`.
Manual snapshots can be generated by sending a `POST /api/database/backup` request or clicking the **Backup SQLite** button on the dashboard sidebar.
